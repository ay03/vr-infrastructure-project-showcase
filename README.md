# Virtual Reality-Based Infrastructure Reconstruction

## 🏗️ Overview

This final-year capstone project demonstrates how raw LiDAR data can be transformed into immersive 3D environments for infrastructure simulation and urban planning. It features a virtual walkthrough of reconstructed city zones using Autodesk ReCap, Civil 3D, and Unreal Engine. Potential applications include smart city development, public safety planning, and post-disaster infrastructure reconstruction.

## 🔧 Technologies Used

- **LiDAR datasets** – for terrain and point cloud input
- **Autodesk ReCap** – for importing and filtering LiDAR point clouds
- **Autodesk Civil 3D** – for terrain modeling and infrastructure layout
- **Unreal Engine** – for real-time rendering and virtual reality walkthrough
- **Metaverse integration** – conceptual visualization in a shared immersive space

## 💡 Project Goal

To bridge the gap between raw geospatial data and intuitive visualization by creating an immersive VR planning tool accessible to both technical experts and decision-makers.
